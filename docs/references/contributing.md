# Contributing

## Ground Rules

- **Never edit `docs/<collection>/`** — generated by `pull-docs`; fix content in the source repo's `docs/` instead
- Keep the SPA dependency-light — current deps: SolidJS, solid-router, oRPC, zod, marked, UnoCSS
- Deploy (`bun run deploy`) only after user confirmation — it ships production

## Process

1. Open an issue or discuss in the wrikka org
2. `bun run pull-docs && bun run dev` to verify locally
3. `bun run verify` must pass (typecheck + build)
4. Small, focused PRs against `main`

## Code Style

- TypeScript strict; SolidJS JSX
- UnoCSS utility classes; `i-mdi:*` icons
- oRPC procedures in `src/server/router.ts`; client calls via `src/lib/orpc.ts`
