# FAQ

## Why did my edits in `docs/` disappear?

`docs/` is generated by `bun run pull-docs` — collection folders (`docs/bun-packages/`, `docs/rust-*/`) get overwritten. Edit the source repo's `docs/` instead. Only the project pages (index, project/, getting-started/, development/, references/) are committed here.

## How do I add a new docs collection?

Add a `sources` entry in `create-docs.config.ts` (see [Usage](../getting-started/usage.md#adding-a-doc-source)), run `bun run pull-docs`, verify `docs/manifest.json`.

## How do I document a private repo?

Set `optional: true` + `repo` on the source; CI needs `GH_PAT` with read access. Locally, point `localDir` at a sibling checkout.

## Where do translations come from?

`.github/workflows/translate.yml` — manual dispatch with `locales` + `apply`, using `TRANSLATE_API_KEY`/`OPENAI_API_KEY` against an OpenAI-compatible endpoint. Results commit back to `main`.

## Can I run the API without deploying?

`bunx wrangler dev` runs the Worker locally with bindings (`ASSETS`, `AI`). `vite dev` only serves the SPA.

## Why no unit tests?

The project is a thin SPA + Worker — verification is `bun run verify` (typecheck + build) plus `preview` smoke. See [Testing](../development/testing.md).
