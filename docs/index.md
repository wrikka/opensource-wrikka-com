# opensource-wrikka-com

SolidJS documentation site for the wrikka open-source monorepo, deployed on Cloudflare Workers. The site catalogs every workspace in the parent monorepos (Bun/TypeScript packages, Rust apps and libraries) and renders generated markdown docs.

> Note: `docs/` also holds **generated content** pulled from source repos at build time (`docs/<collection>/`, `manifest.json`, `sources.json` — gitignored). The pages below document this project itself.
