# Troubleshooting

## A collection is missing after `pull-docs`

- Private sources are `optional: true` — they skip silently. Check `docs/manifest.json` for the actual collection list.
- Without `GITHUB_TOKEN`, `localDir` must resolve — it tries `../wpackages/...`, `../...`, `../../...` relative to the repo. Confirm the sibling checkout exists.
- With `GITHUB_TOKEN`, verify it can read the source repo (private repos need `GH_PAT` in CI).

## `docs.get` returns `NOT_FOUND` for an existing entry

The manifest lists the doc but the `.md` asset wasn't pulled — re-run `bun run pull-docs` and rebuild (`bun run build`).

## Search returns nothing

`docs.search` needs `public/search-index.json` — generated by `bun run build` (`generate-seo.ts`). Run a full build; `vite dev` alone doesn't emit it.

## `docs.ask` fails with `PRECONDITION_FAILED`

The `AI` binding only exists inside the Worker (`wrangler dev` or production). `vite dev` alone can't reach it.

## SPA shows a blank page / 404 on refresh

Confirm `wrangler.toml` still has `not_found_handling = "single-page-application"` and the request isn't under `/rpc/` (those go to oRPC, not assets).

## `wrangler deploy` fails in CI

The workflow skips deploy silently when `CLOUDFLARE_API_TOKEN` is missing — check the "Check deploy token" step output. For auth errors, rotate `CLOUDFLARE_API_TOKEN` and confirm `CLOUDFLARE_ACCOUNT_ID`.
